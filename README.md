
# 📚 ReadIt ( Library Management System)
A command-line library management system built with originally Pyhton but revised with JavaScript

## Features
- Add books
- View books
- Search books
- Delete books
- Save books to a text file
- Error handling
  ## Added Features
- Register members
- Manage borrow transactions
- Time limit for  borrowed book

## Technologies 
- Vanilla JS
- Node.JS

## How To Run

npm start
